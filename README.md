This is a simple program designed to integrate the Dog Facts API with
a simple but pleasing UI.

The components
app.js - uses fetch API to get information from Dogs API. Seperate functions for breed, Groups and Facts
script.js  - Contains  4 fucntions, one for setting up a list of breeds, and others for loading groups and random fact
index.html - a simple HTML page
style.css - Thank you gemini for making it pretty!

How to run
Navigate to the project directory in your terminal.

Run npm install to ensure all dependencies (Express) are present.

Execute node app.js to start the server.

Open your browser to http://localhost:3000.
